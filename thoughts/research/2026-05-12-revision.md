## ВЕРДИКТ

Ядро MVP **работает** (Upload → Gladia → Groq → Credits). Но есть **3 критических проблемы**, которые блокируют production-запуск, и **1 ложь в бэклоге** (задача A2 помечена закрытой, но не сделана).

---

## 🔴 КРИТИЧЕСКИЕ (блокируют прод)

### C1 — Storage bucket PUBLIC (A2 не закрыта)
- `0001_init.sql:95` — `public = true`, RLS policy "public read"
- Все загруженные аудиофайлы доступны публично по прямому URL
- В BACKLOG.md A2 помечена как **✅ Закрыто в Фазе 5** — это неправда
- Блокирует юридические/медицинские use-cases (GDPR, конфиденциальность)
- **Фикс:** `public = false` в bucket + signed URLs при каждом GET /api/transcribe/[id]

### C2 — `anonymous_usage` без RLS
- Таблица не защищена: любой с anon-ключом может прочитать все IP + used_seconds
- Сейчас смягчена тем, что доступ только через admin-клиент, но одна ошибка — и утечка
- **Фикс:** `ALTER TABLE anonymous_usage ENABLE ROW LEVEL SECURITY` + policy `USING (false)`

### C3 — `adjustCredits` fire-and-forget
- `src/app/api/transcribe/[id]/route.ts` — вызов `.catch()` без блокировки
- Если RPC упадёт — пользователь получит 200, а кредиты не вернутся/не скорректируются
- **Фикс:** `await adjustCredits(...)` или гарантировать idempotency через retry

## 🟡 ВЫСОКИЙ ПРИОРИТЕТ

### H1 — Polling без лимита попыток
- `src/app/transcription/[id]/page.tsx` — `setTimeout(tick, 5000)` без счётчика
- Если Gladia зависнет, клиент будет пулить вечно
- **Фикс:** MAX_ATTEMPTS = 120 (10 минут), затем показать ошибку

### H2 — duration_hint без валидации (V1 частично)
- `/api/transcribe/route.ts:66` — `Math.round(Number(durationHintRaw))` без проверки границ
- Можно передать отрицательное или огромное число → резервирование сломается
- **Фикс:** `duration_hint > 0 && duration_hint < 14400` (макс 4 часа)

### H3 — Неиспользуемые зависимости
- `@anthropic-ai/sdk@0.88.0` — не используется, BACKLOG A8 уже давно
- `next-pwa@5.6.0` — в deps, но `next.config.ts` пустой, не настроен
- **Фикс:** `npm uninstall @anthropic-ai/sdk next-pwa`

### H4 — next.config.ts пустой
- Нет security headers, нет image optimization, нет env validation
- **Фикс:** минимальный hardening (X-Frame-Options, CSP, и т.д.)

## 🔵 СРЕДНИЙ ПРИОРИТЕТ

- 0 тест-файлов, нет jest/vitest
- Критические модули (credits.ts, gladia.ts) полностью untested
